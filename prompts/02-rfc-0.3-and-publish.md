## 1. Fix the four contradictions (OPEN.md §Contradictions)

- §11.1: inbox messages are `kind: decision` with `actions: [archive, keep]`; all other mail is `kind: artifact` with no actions. Artifacts never carry actions (§4.1, §4.2 stand).
- §3 restricted YAML: allow block sequences whose items are one-level mappings of scalars, so §4.4 choice objects fit the file form. Nothing deeper. Booleans in such mappings are written `"true"`/`"false"` and typed after parsing.
- §4.4 / §7.3: `edited` is always a valid *decision* (§7.3 stands). The `edit` entry in `actions` only controls whether a head *offers* free text. Say so in both sections. `edit` itself is never recorded as a decision value.
- Fix the §4.3 → §4.2 cite for acknowledgement in `docs/skeleton.md`.

## 2. Resolve the three design findings

- **Id grammar (OPEN.md #39, #40).** Widen `upstream-id` to also allow percent-encoded octets (`%XX`). Add to §5: when an upstream key is unbounded or not representable, a producer MAY use a hash of it as `upstream-id`, and SHOULD say which hash in its documentation; a source with no stable key cannot satisfy the determinism rule and the card MUST say so in its body. Update `id.ts` and its tests; keep the IMAP connector on sha256 but document it.
- **Producer state (OPEN.md #41).** Keep `x-` preservation at SHOULD. Move the IMAP connector's mailbox/uid lookup into a local state file beside the cursor; it must not depend on the head echoing `x-imap-*` fields.
- **Poison cards (OPEN.md #42).** Add to §7.2: a producer MAY park a change whose processing has failed repeatedly, advance its cursor past it, and MUST report parked changes (at least by logging; a head MAY offer a way to surface them). Implement parking in `runProducer` with a configurable attempt limit (default 5) and an `onParked` callback. Test it.

## 3. Add `GET /` discovery (OPEN.md #46, and §3.1 already references it)

Define in §7 a `GET /` response: `{ "protocol": "pbcp/1", "owner": "<person id>", "extensions": [], "render": { "mermaid": [...] } }`. Add `HeadClient.describe()`. The IMAP connector reads `to_person` from it when `PBCP_TO_PERSON` is unset.

## 4. Make error codes normative (OPEN.md #48)

Add a table to §7.4 mapping each status to its stable `code` values, taken from `errors.ts`. Add `404 Not Found` to the status table. The client may then trust `error` bodies without the fallback heuristic; simplify `head.ts` accordingly.
